# NoteForge AI

AI-powered study notes app built with React Native and Expo.

## Features

- Paste study material
- Select PDF/text documents
- Quick revision notes
- Full study notes
- Key points
- Key terms
- Flashcards
- MCQ test
- PDF export
- Hindi/English study support

## Tech Stack

- React Native
- Expo
- TypeScript
- Python/FastAPI (planned)
- AI API (planned)
- PostgreSQL (planned)
